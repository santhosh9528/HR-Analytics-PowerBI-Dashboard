# HR Analytics – Overview & Attrition Dashboard

## 📌 Project Overview

This project presents an interactive **HR Analytics Dashboard** developed using **Microsoft Power BI**.

The objective of this project is to analyze workforce data and provide meaningful insights into **employee demographics, workforce distribution, departments, job roles, and employee attrition**.

The project contains two main dashboard views:

1. **HR Overview Dashboard**
2. **Employee Attrition Dashboard**

These dashboards help HR teams and management understand the overall workforce and identify employee attrition patterns that may require attention.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze overall workforce composition
- Monitor important HR KPIs
- Understand employee distribution
- Analyze employees across departments
- Analyze employees across job roles
- Understand workforce demographics
- Measure employee attrition
- Identify attrition patterns
- Compare attrition across different employee groups
- Identify areas with higher employee turnover
- Support HR decision-making using data
